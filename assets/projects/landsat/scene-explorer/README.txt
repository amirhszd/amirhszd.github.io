values outside the display scale. Source statistics and clipped fractions appear in the UI.

is capped at 10 K. RGB uses photographic WebP compression.
Source rasters: 100 m. Reprojected to Web Mercator, nearest-neighbor, max 2048 px.
Display images are not intended for exact numeric retrieval.
